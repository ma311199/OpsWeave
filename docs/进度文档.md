## 2. 后端已完成功能

### 2.1 认证与权限 ✅

- 注册、登录、登出、`/me`、管理员用户列表（`src/opsweave/api/routes/users.py`）。
- PBKDF2-SHA256 密码哈希；session token SHA-256 哈希入库，HttpOnly Cookie（7 天）；Bearer token 与 WebSocket `bearer.<token>` 子协议。
- 三级角色 `admin / ops_engineer / viewer` × 四类资源权限矩阵（`src/opsweave/auth/permissions.py`）。
- admin 账号经 `ADMIN_INITIAL_PASSWORD` 引导创建。

### 2.2 系统配置 ✅

- 两级配置：`.env` / 环境变量为默认值，SQLite `configs` 表覆盖（密钥不落库，仅环境变量）。
- 管理员配置 API：LLM / Embedding / Milvus / Agent / 远程 MCP Server 读写，密钥掩码返回。
- LLM、Embedding、Milvus 连通性测试；Milvus collection 增删改查与字段 Schema 校验。

### 2.3 知识库管理 ✅

- 文档上传绑定 collection，按用户隔离，管理员跨用户可见。
- 八种切分策略：`fixed` / `sliding` / `sentence` / `paragraph` / `recursive` / `structure`（markdown/html/latex）/ `semantic` / `summary`。
- 完整审批流：上传 → 申请（pending）→ 批准/拒绝/撤销 → 后台构建 → completed/failed。
- 入库前逐块校验 embedding token 上限；Milvus 写入后回查核验；删除文档级联清理文件/SQLite/Milvus。

### 2.4 检索 ✅

- LlamaIndex `VectorStoreIndex` + Milvus；非管理员按 `user_id` 过滤（`src/opsweave/retrieval/`）。
- **直连检索 LangGraph 管道**（`src/opsweave/agents/retrieval_pipeline.py`）：connect_index（按 collection 缓存索引，配置/集合变更自动失效）→ decompose（占位）→ search（多子查询合并去重 + top_k）→ rerank（占位）；`/api/retrieval/search` 支持 `collection_name` / `options` 参数。

### 2.5 Agent 聊天与 MCP ✅

- LangGraph 状态机：`decide → tool_call → decide` 循环，支持直接回答、澄清、工具调用、迭代上限（`src/opsweave/api/agents.py`）。
- WebSocket 协议 `/api/chat/ws/chat`：`thinking / tool / approval_required / clarify / answer / done / error`。
- 本地 stdio FastMCP Server 提供 `search_knowledge`；管理员可配远程 Streamable HTTP MCP Server，工具清单按 `tool_id` 合并暴露。
- 工具审批：`readOnlyHint === true` 直接执行，否则写 SQLite 待审批；发起人或管理员处理，批准后同步执行，禁止重复处理。

### 2.6 记忆 ✅

- 短期：SQLite `chat_messages`，按用户 + 会话隔离，每会话保留最近 40 条。
- 长期：`data/documents/{username}/memory.md`，聊天时 `remember` 字段显式追加。
